# Disco Turbo

Website for Disco Turbo — a Copenhagen graphic design agency and print studio.

Built with Next.js, TypeScript and Tailwind CSS.

## Run locally

Needs Node.js 20+ and npm. From this folder:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Where to edit

- Copy, clients and contact details: `src/lib/site.ts`
- Homepage layout: `src/app/page.tsx`
- Colours: `src/app/globals.css`
- Navigation: `src/components/SiteHeader.tsx`
- Case images: `public/cases/`
- Logo: `public/disco-turbo-logo.svg` (exported from DiscoTurbo Logo 3 2026)
- Typeface: `src/fonts/Inter-V.otf` (Inter V by Rasmus Andersson — not Google Inter)
