# Disco Turbo

Copenhagen graphic design studio and print shop website.

## Run locally

Needs Node.js 20+ and npm:

```bash
npm install
npm run dev
```

Then open `http://localhost:5173`.

Without Node, from this folder:

```bash
python3 serve.py
```

## Replace content

Edit `src/content.js` for all copy, contact details, colours and client names.
